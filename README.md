CampusPilotAI 🎓

An AI-Powered Student Productivity Agent

CampusPilotAI is an AI agent designed to help college students organize their studies, prepare for exams, and break large assignments into manageable tasks.

🚀 Features

- AI Study Planning: Generates study plans based on subjects, available time, and exam preparation needs.
- Timetable Generation: Creates day-wise study schedules.
- Study Hour Calculator: Calculates total available study time.
- Assignment Breakdown: Divides assignments into smaller, manageable steps.
- Conversational Interface: Communicates with users through ASI:One using the Agent Chat Protocol (ACP).

🛠️ Technology Stack

- Python
- ASI:One
- Agentverse
- uAgents
- Agent Chat Protocol (ACP)

💡 Example Use Case

A student has Physics, Mathematics, and Programming exams in seven days and can study four hours daily.

CampusPilotAI can calculate the available study hours and generate a structured revision timetable.

🏗️ Project Status

The initial prototype supports conversational study planning, timetable generation, study-hour calculations, and assignment breakdown.

Persistent task storage, calendar integration, and automated reminders are planned improvements and are not yet implemented.

🔒 Security

Never publish API keys, passwords, or other secrets in the repository.

👨‍💻 Project Goal

To make academic planning simpler and more accessible through an AI-powered student productivity agent.
